# Button Clicker Game

> [!WARNING]  
> Some assets have been omited from this repo to comply with the licenses of some assets used in this game.

## Description
Button Clicker is a satisfying clicker game where you click a big red button.
Click the button to earn more money to upgrade your button clicking power.
